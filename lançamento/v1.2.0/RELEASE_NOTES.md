## ❓ Perguntas Frequentes

**P: Como faço para não gostar de uma música?**  
R: Durante a reprodução, toque no botão thumbs-down. A música é pulada imediatamente e NUNCA mais toca para você.

**P: Posso importar minhas playlists do Spotify?**  
R: Sim! Menu → Importar Playlist → Spotify → Cole o link. O app busca todas as músicas no YouTube Music automaticamente.

**P: Minhas preferências desaparecem se reinstalo o app?**  
R: Não! Tudo é salvo no seu dispositivo. As configurações de "Não Gostei" persistem entre reinstalações.

**P: O app funciona sem internet?**  
R: Parcialmente. Você ouve músicas já salvas, mas streaming precisa de internet. "Não Gostei" funciona offline.
